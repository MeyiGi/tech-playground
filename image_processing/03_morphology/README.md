# Морфология — домашняя работа

На последнем слайде нужно реализовать изученные алгоритмы и сравнить с библиотеками. На слайде 17 отдельно задан Zhang–Suen.

## Что читать

- `morphology.py` — алгоритмы вручную: обычные циклы, условия, минимум и максимум.
- `main.py` — читает картинку, запускает алгоритмы и сохраняет результат.
- `compare.py` — отдельное сравнение с OpenCV и SciPy, как требует последний слайд. В самом решении готовые функции морфологии не используются.

OpenCV в `main.py` используется только для чтения и сохранения изображений. NumPy — для массивов. Результаты лежат в `results/`.

## Запуск

Окружение `.venv` уже подготовлено:

```bash
.venv/bin/python main.py
```

Отдельно сравнение и тесты:

```bash
.venv/bin/python compare.py
.venv/bin/python -m unittest -q
```

Для установки в другом месте: `python3 -m pip install -r requirements.txt`.

## Правила

| Операция | Как считается |
|---|---|
| Эрозия | Минимум среди соседей, выбранных маской |
| Дилатация | Максимум среди выбранных соседей |
| Opening | Эрозия, затем дилатация |
| Closing | Дилатация, затем эрозия |
| Контур | Исходная картинка − эрозия |
| Градиент | Дилатация − эрозия |
| White top-hat | Исходная картинка − opening |
| Black top-hat | Closing − исходная картинка |

В Zhang–Suen и Guo–Hall проверяются восемь соседей каждого белого пикселя. В каждом из двух подшагов пиксели сначала отмечаются, затем удаляются одновременно. Повторяем до отсутствия изменений. Формулы записаны прямо в коде. Скелет по эрозиям отдельно накапливает остатки после восстановления каждого эродированного слоя.

Для неплоского элемента `heights` задаёт добавки к яркости: при эрозии их вычитаем, при дилатации прибавляем. Нулевые высоты тоже участвуют; активные позиции выбирает `kernel`.

Для простоты ядро имеет нечётные размеры и центр посередине. Для плоской морфологии используем симметричные маски, например квадрат или крест. Граница: 255 для эрозии, 0 для дилатации. В thinning и скелете по эрозиям за границей нулевой фон. Числа хранятся в целочисленном типе без переполнения; до 0–255 ограничиваются только при сохранении PNG. Изображение — двумерная матрица яркостей 0–255; в thinning все ненулевые пиксели считаются объектом.
