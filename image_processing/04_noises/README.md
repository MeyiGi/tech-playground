# Удаление шума на изображении

Сравнение фильтра Гаусса, медианного фильтра и фильтрации через Фурье.
Под каждым результатом показана гистограмма распределения яркостей.
Для простоты работаем с изображением в оттенках серого: яркость от 0 до 255.

## Запуск

Нужен Python 3.10 или новее. Команды выполняются из этой папки:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

В Windows вместо активации можно запускать `.venv\Scripts\python.exe`.
Без аргументов программа создаёт тестовую картинку и добавляет гауссов шум
и шум «соль и перец». Seed равен 42, поэтому пример повторяется при запуске.

Своя зашумлённая фотография:

```bash
python main.py "photo.jpg"
```

На свою картинку программа дополнительный шум не накладывает.
Изображения сохраняются в `results/`: `0.png` — до обработки,
`1.png` — Гаусс, `2.png` — медиана, `3.png` — медиана затем Гаусс,
`4.png` — Фурье. Общая иллюстрация — `comparison.png`.
При повторном запуске эти файлы перезаписываются.
В демонстрационном режиме сохраняется и чистый исходник `clean.png`.

Для запуска без окна:

```bash
MPLBACKEND=Agg python main.py --no-show
```

## Что происходит

1. **Гаусс.** Пиксель заменяется взвешенным средним соседей: ближние
   пиксели влияют сильнее. Окно 5×5, sigma = 1. Уменьшает случайный шум,
   но размывает границы.
2. **Медиана.** Берём окно 3×3, сортируем девять яркостей и выбираем среднюю
   по порядку. Хорошо убирает отдельные чёрные и белые точки.
3. **Медиана → Гаусс.** Сначала убираем точки, потом сглаживаем оставшийся
   шум. Дополнительное сглаживание также может стереть мелкие детали.
4. **Фурье.** `fft2` переводит изображение в частоты. Умножаем спектр на
   плавную гауссову маску и возвращаемся через `ifft2`. Высокие частоты
   ослабляются: шум уменьшается, но резкие границы тоже сглаживаются.
   Sigma маски равна 0.08 цикла на пиксель; меньшая sigma сильнее размывает.
   Это другой способ сглаживания, а не универсальное удаление любого шума.
5. **Гистограмма.** По горизонтали яркость, по вертикали число пикселей.
   Она показывает распределение, но не расположение шума. По одной
   гистограмме нельзя определить качество очистки. Выравнивание здесь
   не применяется.

В примере выводится MSE — средний квадрат разности с чистым исходником.
Меньшая ошибка означает более точное восстановление по этой метрике.
Для своей фотографии MSE не считается: чистой версии нет.
Кроме ошибки нужно смотреть на границы, надпись и мелкие детали.

## Что объяснить на защите

Разницу между средним и медианой; зачем нужны прямое и обратное Фурье;
что означают оси гистограммы; почему сильное сглаживание убирает и шум,
и детали. Гаусс и медиана взяты из OpenCV, а частотная маска записана
явно в `fourier_filter`. Все методы используют фиксированные параметры:
на другой фотографии лучший результат может дать другой фильтр.
