# Градиент и границы изображения

Вся программа в `main.py`. Картинка: `data/cat_image.jpg`.

```bash
python -m pip install -r requirements.txt
python main.py
```

Запускайте из этой папки. Программа уменьшает картинку до 500×500 для
быстрого прохода циклами и показывает три изображения.

Для каждого пикселя берётся окно 3×3. Две свёртки Собеля дают `gx` и `gy`.
Модуль градиента: `sqrt(gx² + gy²)`. После перевода в диапазон 0–255
значения больше 50 выделяются белым — это границы.

Порог можно менять в строке `edges = (gradient > 50) * 255`.
