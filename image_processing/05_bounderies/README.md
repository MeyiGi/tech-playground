# Свёртка изображений: градиент и границы

Простая учебная программа на Python. Запустите её, выберите картинку —
появятся оригинал, модуль градиента и чёрно-белые границы.

## Запуск

```bash
python -m pip install -r requirements.txt
python app.py
```

Если окружение `.venv` уже создано, в Linux можно запустить так:

```bash
.venv/bin/python app.py
```

Нужен рабочий стол с поддержкой окон. Для Linux также нужен Tkinter
(в Ubuntu/Debian пакет `python3-tk`).

## Как работает программа

1. Изображение переводится в оттенки серого: двумерную матрицу яркости.
2. Две свёртки с ядрами Собеля находят изменения яркости: `gx` и `gy`.
3. Для каждого пикселя вычисляется модуль градиента:

   ```python
   magnitude = np.sqrt(gx ** 2 + gy ** 2)
   ```

4. Модуль переводится в диапазон 0–255 для отображения. Если все значения
   нулевые, результат тоже нулевой.
5. Значения больше порога 50 становятся белыми границами, остальные — чёрными:

   ```python
   edges = (gradient > threshold).astype(np.uint8) * 255
   ```

Порог меняется в `app.py`: `gradient_and_edges(gray, threshold=50)`.
Больше порог — меньше слабых границ. Порог применяется к нормированному
градиенту, поэтому зависит от самого сильного перепада на картинке.

## Где смотреть код

- `app.py` — выбор файла, модуль градиента, порог и показ результата.
- `processing.py` — ручная свёртка `convolve2d`, ядра Собеля и чтение картинки.
  Дополнительные функции Canny и Laplacian для этого задания не нужны.

Главная часть свёртки — обход строк и столбцов:

```python
for y in range(height):
    for x in range(width):
        patch = padded[y:y + 3, x:x + 3]
        result[y, x] = np.sum(patch * flipped)
```

`patch` — окно 3×3 вокруг пикселя, `flipped` — ядро, повёрнутое на 180°.
Произведения складываются в новое значение пикселя. За краями изображения
повторяется ближайший пиксель. Вычисления идут в `float64`, чтобы сохранять
отрицательные значения и избежать переполнения.
