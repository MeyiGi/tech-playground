# Лаборатория свёртки: Sobel, Canny и Laplacian

Учебное приложение на Python и Tkinter. Sobel и Laplacian вычисляются
вручную: вложенные циклы проходят по **каждому пикселю**, умножают окно 3×3
на перевёрнутое ядро и суммируют девять произведений. `cv2.Sobel()` и
`cv2.Laplacian()` в основной реализации не используются.

## Установка и запуск

Рекомендуется Python 3.10 или новее. Откройте терминал в этой папке.

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

Windows (PowerShell, активация окружения не требуется):

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

Tkinter входит в стандартную библиотеку, но требует системного Tk.
Если Linux сообщает `No module named tkinter`, в Ubuntu/Debian установите
`sudo apt install python3-tk`. На Windows используйте установщик Python
с компонентом Tcl/Tk; на macOS нужна сборка Python с поддержкой Tk.
Для GUI требуется графическая сессия. `opencv-python-headless` содержит
нужные алгоритмы OpenCV; окна рисует Tkinter, поэтому GUI OpenCV не нужен.

## Как пользоваться

1. Нажмите **«Загрузить изображение»**, выберите PNG, JPEG, BMP или TIFF.
   Цветное изображение преобразуется в матрицу `gray` типа `uint8`, формы
   `(H, W)`. Координаты: `gray[y, x]`, начало — левый верхний угол.
2. Дождитесь вычислений. Индикатор показывает работу фонового потока;
   большие изображения обрабатываются медленнее из-за учебных циклов.
   Разрешение не уменьшается, все пиксели участвуют в вычислениях.
3. Выберите **Sobel**, **Canny**, **Laplacian** или **«Сравнить все»**.
   У Sobel доступны знаковые Gx/Gy, их нормированные абсолютные значения
   и общий модуль. Красный цвет знаковой карты означает положительную
   производную, синий — отрицательную; шкала находится рядом.
4. Для Canny задайте целые пороги `0 ≤ нижний < верхний ≤ 255` и нажмите
   **«Применить пороги»**. Не применённые значения полей не меняют результат;
   действующие пороги указаны в строке состояния.
5. На вкладке **«Как движется ядро 3×3»** щёлкните по серому изображению
   или введите координаты и нажмите **«Показать»**. Видны окно, перевёрнутое
   ядро, девять произведений, сумма и модуль градиента.
   **«Шаг →»** перемещает окно на один пиксель; **«Движение»** запускает
   анимацию, **«Пауза»** останавливает её. После последнего столбца окно
   переходит на следующую строку, после последнего пикселя — к первому.
6. **«Сохранить результат»** сохраняет карту выбранного метода в исходном
   размере H×W. Для Sobel сохраняется нормированный модуль. В режиме
   сравнения сохраняется иллюстрация всех методов с подписями.
   Для точного сохранения пикселей выбирайте PNG: JPEG вносит потери.

## Математика

### 1. Изображение как матрица

Цветной пиксель имеет три компоненты; в сером изображении достаточно
одного значения яркости от 0 (чёрный) до 255 (белый).
OpenCV использует приблизительно:

```text
I = 0.299 R + 0.587 G + 0.114 B
```

Индекс `y` задаёт строку, `x` — столбец. В вычислениях данные переводятся
в `float64`: производная может быть отрицательной и превышать 255,
поэтому считать её в `uint8` нельзя.

### 2. Двумерная свёртка и обработка краёв

Для ядра K размером 3×3:

```text
R[y,x] = Σ(i=-1…1) Σ(j=-1…1) I_padded[y-i, x-j] K[i+1,j+1]
```

Здесь `I_padded` обозначает изображение, продолженное за исходные границы;
координаты в формуле отсчитываются относительно исходного изображения.
В коде удобнее взять окно `P` вокруг пикселя, перевернуть ядро на 180°
и вычислить `sum(P * K[::-1, ::-1])`.
`*` — **поэлементное** умножение, а не матричное произведение `@`.

Без переворота ядра получается корреляция. В обработке изображений её
тоже часто называют свёрткой. Здесь используется именно математическая
свёртка, и знаки ядер выбраны с учётом этого переворота.

Чтобы вычислить результат у рамки, `np.pad(..., mode="edge")` добавляет
по одному пикселю со всех сторон, повторяя ближайшее значение:

```text
Исходная матрица:     После padding:
  a b                  a a b b
  c d                  a a b b
                       c c d d
                       c c d d
```

Поэтому выход имеет те же H×W, корректно обрабатываются даже изображения
1×1, 1×W и H×1. Постоянная яркость не создаёт искусственную рамку,
которая появилась бы при дополнении нулями.

### 3. Sobel: первые производные

В программе хранятся ядра **свёртки**:

```text
Kx = [ 1  0 -1 ]       Ky = [ 1  2  1 ]
     [ 2  0 -2 ]            [ 0  0  0 ]
     [ 1  0 -1 ]            [-1 -2 -1 ]
```

При умножении на окно используются их перевёрнутые варианты:

```text
Wx = [-1  0  1 ]       Wy = [-1 -2 -1 ]
     [-2  0  2 ]            [ 0  0  0 ]
     [-1  0  1 ]            [ 1  2  1 ]
```

`Gx = I * Kx` приближает изменение яркости вдоль x, `Gy = I * Ky` — вдоль y.
Коэффициенты `1, 2, 1` одновременно сглаживают в поперечном направлении.
Здесь не вводится деление на 8: используются исходные отклики Sobel.
Положительный Gx означает рост яркости вправо, положительный Gy — вниз.
Gx особенно хорошо выделяет вертикальные границы, Gy — горизонтальные:
название компоненты означает направление **изменения** яркости.

Градиент — вектор `(Gx, Gy)`. Его длина вычисляется для каждого пикселя:

```text
G[y,x] = √(Gx[y,x]² + Gy[y,x]²)
```

Внутри однородного объекта соседние яркости близки, поэтому положительные
и отрицательные слагаемые почти сокращаются. На границе яркость быстро
меняется: производные и модуль обычно велики. Текстура, тень и шум тоже
могут давать большой градиент, поэтому это признак перепада яркости,
а не гарантия смысловой границы объекта.

Для неотрицательной карты силы отклика A визуализация использует:

```text
N[y,x] = round(255 × A[y,x] / max(A))
```

При `max(A)=0` возвращается чёрная матрица. Это масштабирование относительно
максимума с сохранением нуля: минимум не вычитается. Для Sobel берутся
`A=G`, `A=|Gx|` или `A=|Gy|`. Знаковые Gx/Gy хранятся отдельно без потерь.
Карты нормируются независимо, поэтому одинаковая яркость на разных картах
не означает одинаковую исходную силу производной.

### 4. Числовой пример для одного пикселя

Возьмём окно вокруг центрального пикселя:

```text
P = [ 0  0 100 ]
    [ 0  0 100 ]
    [ 0  0 100 ]
```

Слева темно, справа светло. Для перевёрнутых весов Wx:

```text
P × Wx = [ 0  0 100 ]
         [ 0  0 200 ]
         [ 0  0 100 ]

Gx = 0 + 0 + 100 + 0 + 0 + 200 + 0 + 0 + 100 = 400
```

Для Wy:

```text
P × Wy = [ 0  0 -100 ]
         [ 0  0    0 ]
         [ 0  0  100 ]

Gy = -100 + 100 = 0
G = √(400² + 0²) = 400
```

Это вертикальная граница. Если максимальный модуль всего изображения
равен 400, нормированное значение этого пикселя будет 255.
При другом глобальном максимуме результат нормализации изменится.

### 5. Canny

Программа сначала применяет гауссово сглаживание 5×5, σ=1, затем
`cv2.Canny(..., L2gradient=True)`. Этапы детектора:

1. Вычисление градиента.
2. Подавление немаксимумов вдоль направления градиента: линии становятся тоньше.
3. Два порога: сильные и слабые кандидаты в границы.
4. Гистерезис: слабые кандидаты сохраняются, если связаны цепочкой
   с сильными; остальные удаляются.

Результат — бинарная карта 0/255. Пороги относятся к силе градиента,
а не к исходной яркости. Диапазон 0…255 выбран для удобства учебного GUI;
сам градиент Sobel способен превышать 255. Малые пороги обычно добавляют
детали и шум, большие могут убирать слабые границы.

### 6. Laplacian: вторая производная

```text
ΔI ≈ ∂²I/∂x² + ∂²I/∂y²

K = [ 0  1  0 ]
    [ 1 -4  1 ]
    [ 0  1  0 ]

R[y,x] = I[y-1,x] + I[y+1,x] + I[y,x-1] + I[y,x+1] - 4I[y,x]
```

Ядро симметрично, поэтому переворот его не меняет. Постоянная или
линейно меняющаяся яркость внутри изображения даёт нулевую вторую
производную. Изменение наклона яркости даёт положительный или отрицательный
отклик. Для просмотра программа нормирует `|R|`, исходный знак остаётся
в `laplacian_raw`.

Это карта силы отклика второй производной; она не выполняет поиск переходов
через ноль или утончение контуров. На ступенчатой границе возможна двойная
полоса. Сглаживание перед ручным Laplacian здесь не применяется, чтобы
показать работу самого ядра и его чувствительность к шуму.

## Сравнение методов

| Метод | Что вычисляет | Результат | Особенности |
| --- | --- | --- | --- |
| Sobel | Две первые производные и длину градиента | Карта силы перепада | Показывает направление; контуры могут быть толстыми |
| Canny | Градиенты, подавление немаксимумов и гистерезис | Тонкие бинарные контуры | Требует выбора порогов; использует сглаживание |
| Laplacian | Сумму вторых производных | Модуль знакового отклика | Чувствителен к шуму, возможны двойные контуры |

## Как объяснить на защите

«Я преобразую изображение в двумерный массив яркостей. Для каждого пикселя
беру его окружение 3×3. Переворачиваю ядро свёртки, умножаю его веса на
соответствующие яркости и складываю девять произведений. На краях повторяю
ближайший пиксель, поэтому результат имеет исходный размер.

Для Sobel делаю это с двумя ядрами: получаю изменение яркости по x и y.
Затем нахожу длину вектора градиента по теореме Пифагора. Большая длина
показывает резкий перепад яркости. Для Laplacian использую ядро второй
производной, а для отображения беру модуль отклика. Canny запускаю через
OpenCV: после сглаживания он выделяет тонкие контуры с двумя порогами.
Визуализация и интерфейс не заменяют расчёты: ручная свёртка находится
в `convolve2d`, а модуль каждого пикселя — в `derivatives`».
