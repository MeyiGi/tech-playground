# Круг и нормализация пикселей

Все вычисления выполняются вручную в списках Python. Pillow (PIL) используется
для чтения, изменения размера, записи и показа изображений. NumPy, OpenCV
и готовые функции нормализации не нужны.

## Запуск

Из этой папки:

```bash
uv sync
uv run python main.py
```

По умолчанию используется `data/cat_image.jpg`. Фотографии не хранятся в Git,
поэтому на другой машине нужно положить туда изображение или указать своё:

```bash
uv run python main.py --input /path/to/photo.jpg --output output --show
```

`--show` открывает изображения в системном просмотрщике; без него достаточно
посмотреть PNG-файлы в папке `output`:

- `original.png` — исходник размером 1600 × 1200;
- `circle_mask.png` — белый круг радиусом 500 на чёрном фоне;
- `multiplied.png` — RGB-каналы внутри круга умножены на 100;
- `normalized.png` — значения внутри круга нормализованы, снаружи исходные пиксели.

## Как это работает

Пиксель RGB — три числа от 0 до 255: красный, зелёный и синий каналы.
Точка входит в круг, если `(x - center_x)² + (y - center_y)² <= radius²`.

При умножении, например, `(40, 100, 200)` превращается в `(4000, 10000, 20000)`.
В обычном RGB такие значения не помещаются. При сохранении пересвеченного
результата явно обрезаем каждый канал до 255: получаем белый `(255, 255, 255)`.
Чёрные и очень тёмные каналы могут не стать белыми.

Для нормализации находим **один общий максимум среди всех RGB-каналов внутри
круга** и пересчитываем каждый канал:

```text
новое значение = значение после умножения × 255 / максимум после умножения
```

Результат округляем вниз до целого. Например, если максимум равен 20000,
то `(4000, 10000, 20000)` станет `(51, 127, 255)`. Один общий коэффициент
сохраняет соотношение каналов. Если максимум равен нулю (весь круг чёрный),
оставляем пиксели без изменений, чтобы не делить на ноль.

Нормализация работает с матрицей **до обрезания** до 255. Из уже белых
пикселей восстановить потерянные детали нельзя. Если исходный максимум в круге
был 255, после нормализации получится исходное изображение: множитель 100
сократится. Это ожидаемый результат.
